# Kevin Bandara — Full-Stack Software Developer & AI Systems Builder

Official personal engineering portfolio of **Kevin Bandara** — Full-Stack Software Developer, AI Systems Builder, and Founder of **Corvento Technologies** & **DanumaAI** based in Colombo, Sri Lanka.

## ⚡ Architecture & Stack

- **Framework**: Next.js 15 (App Router) & React 19
- **3D & Spatial Web**: Three.js (`WebGLRenderer` with interactive Neural RAG Core, Gyroscopic Orbital Microservices, and Vector Lattice modes + hardware-accelerated 3D perspective tilt cards)
- **Styling**: Tailwind CSS v4 (Atmospheric Minimalism & High-Craft Obsidian UI + Neo-Brutalist Swiss Grids)
- **Typography**: `Space Grotesk`, `Inter`, and `JetBrains Mono`

## 🚀 Featured Production Systems

1. **[DanumaAI](https://danumaai.lk/)** — Multi-platform AI-powered educational ecosystem (Web, [Google Play Store](https://play.google.com/store/apps/details?id=com.Lycoryx.danumaai), and [Telegram Bot](https://t.me/DanumaAI_Bot)) built with Next.js, React Native (Expo), Python, MongoDB Atlas, NextAuth, and Gemini API RAG workflows.
2. **[Past Papers Wiki — Custom Booking Engine](https://pastpapers.wiki/)** — Automated reservation and commercial scheduling architecture built with Next.js, Node.js, and MongoDB.
3. **[MemoAI](https://github.com/KevinBandara/MemoAI-Web-Playground)** — Scalable community AI Discord bot (200,000+ historical users across 2,150+ servers) & OAuth2 Web Playground.
4. **[Kev & Thash Sweet Treats](https://kev-thash-sweet-treats.vercel.app/)** — Bilingual (English & Sinhala) e-commerce storefront with direct WhatsApp order serialization.
